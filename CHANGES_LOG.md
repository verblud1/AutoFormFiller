## Как это работает

### 1. Определение базового пути проекта
```python
def get_base_project_dir(self):
    if getattr(sys, 'frozen', False):
        # PyInstaller: используем папку, где находится исполняемый файл
        base_dir = os.path.dirname(sys.executable)
    else:
        # Обычный режим: используем папку с gui.py
        base_dir = os.path.dirname(os.path.abspath(__file__))
```

### 2. Копирование файлов
При загрузке любого файла (реестра или АДПИ):
1. Файл копируется в соответствующую папку проекта (`registry/` или `adpi/`)
2. Если файл с таким же именем уже существует - он заменяется
3. Папки создаются автоматически, если их нет
4. Загрузка данных из исходного файла продолжается как раньше

### 3. Загрузка последних файлов при старте
- При запуске программа ищет файлы в папках `registry/` и `adpi/`
- Если найдено 2+ файла в `registry/`, пользователю предлагается выбрать, какие загрузить
- Если пользователь отказывается или найден 1 файл - загружаются последние по дате изменения

## Преимущества

1. **Работа в PyInstaller**: Файлы сохраняются рядом с исполняемым файлом, а не во временной папке
2. **Удобное управление**: Все загруженные файлы хранятся в известных папках проекта
3. **Автоматическая замена**: Старые файлы автоматически заменяются новыми
4. **Совместимость**: Обратная совместимость с существующим функционалом сохранена

- В режиме PyInstaller файлы копируются в папку рядом с `.exe` файлом
