# Сводка реализации: Копирование файлов в папки проекта

## Задача
Добавить возможность копирования загружаемых файлов (реестр многодетных и АДПИ) в папки проекта с заменой старых файлов, чтобы работало в PyInstaller.

## Решение

### 1. Определение базового пути проекта
Добавлен метод `get_base_project_dir()`, который корректно определяет путь:
- **PyInstaller**: использует папку, где находится `.exe` файл
- **Обычный режим**: использует папку с `gui.py`

### 2. Копирование файлов
Добавлен метод `copy_file_to_project_folder()`:
- Создает целевую папку при необходимости
- Удаляет старый файл с таким же именем
- Копирует новый файл с сохранением метаданных

### 3. Интеграция в загрузку файлов
Модифицированы методы:
- `load_register_file()` - копирует в `registry/`
- `load_adpi_xlsx()` - копирует в `adpi/`

### 4. Улучшенная автозагрузка
`load_last_files()` теперь:
- Использует флаги `register_loaded_at_startup` и `adpi_loaded_at_startup`
- Предотвращает двойную загрузку файлов
- Корректно работает с новыми путями

## Использование

1. При нажатии "Загрузить реестр" файл копируется в `registry/`
2. При нажатии "Загрузить АДПИ" файл копируется в `adpi/`
3. При следующем запуске программа автоматически загружает последние файлы из этих папок
4. В PyInstaller папки создаются рядом с `.exe` файлом

## Примечания

- Папки `registry/` и `adpi/` создаются автоматически
- Старые файлы заменяются без подтверждения
- Конфигурационные файлы не затрагиваются
- Все существующие функции работают как раньше
