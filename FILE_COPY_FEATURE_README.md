# Функциональность копирования файлов в папки проекта

## Обзор

При нажатии на кнопки **"Загрузить файл с реестром многодетных"** и **"Загрузить файл с АДПИ"** выбранные файлы автоматически копируются в соответствующие папки проекта (`registry/` и `adpi/`) с заменой старых версий.

## Преимущества

1. **Работа в PyInstaller**: Файлы сохраняются рядом с исполняемым файлом, а не во временной папке
2. **Удобное управление**: Все загруженные файлы хранятся в известных папках проекта
3. **Автоматическая замена**: Старые файлы автоматически заменяются новыми
4. **Автозагрузка**: При следующем запуске программа автоматически загружает последние файлы из этих папок

## Как это работает

### При загрузке файла:

1. Вы выбираете файл через диалоговое окно
2. Файл загружается и обрабатывается как раньше
3. **Автоматически** файл копируется в папку проекта:
   - Реестр многодетных → `registry/`
   - Файл АДПИ → `adpi/`
4. Если файл с таким же именем уже существует - он заменяется
5. Папки создаются автоматически, если их нет

### При запуске программы:

1. Программа ищет файлы в папках `registry/` и `adpi/`
2. Если найдено 2+ файла в `registry/`, появится диалог:
   ```
   Найдено N файлов в папке registry:
   файл1.xlsx, файл2.xlsx, ...
   Подгрузить из папки?
   ```
3. При выборе "Да" программа попытается автоматически определить, какой файл - реестр, а какой - АДПИ
4. При выборе "Нет" или если найден только 1 файл - загружаются последние по дате изменения

## Особенности в PyInstaller

Когда приложение упаковано в `.exe` с помощью PyInstaller:

- Папки `registry/` и `adpi/` создаются **рядом с исполняемым файлом** (`.exe`)
- Файлы копируются в эти папки, а не во временную директорию PyInstaller
- При следующем запуске программа находит и загружает файлы из этих папок

### Пример структуры после упаковки:

```
C:\Program Files\AutoFormFiller\
├── AutoFormFiller.exe
├── registry\
│   └── реестр_многодетных.xlsx
├── adpi\
│   └── данные_адпи.xlsx
└── ...
```

## Миграция существующих данных

Если у вас уже есть файлы реестра и АДПИ в других папках:

1. Запустите программу
2. Нажмите "Загрузить реестр" и выберите ваш файл
3. Файл автоматически скопируется в `registry/`
4. Аналогично для АДПИ
5. В будущем программа будет использовать файлы из этих папок

## Технические детали

### Определение базового пути

```python
def get_base_project_dir(self):
    if getattr(sys, 'frozen', False):
        # PyInstaller: путь к исполняемому файлу
        base_dir = os.path.dirname(sys.executable)
    else:
        # Обычный режим: путь к gui.py
        base_dir = os.path.dirname(os.path.abspath(__file__))
```

### Копирование файлов

```python
def copy_file_to_project_folder(self, source_path, target_dir, target_filename=None):
    """Копирование файла с заменой существующего"""
    os.makedirs(target_dir, exist_ok=True)
    target_path = os.path.join(target_dir, target_filename or os.path.basename(source_path))

    if os.path.exists(target_path):
        os.remove(target_path)  # Удаляем старый файл

    shutil.copy2(source_path, target_path)  # Копируем с сохранением метаданных
    return True, target_path
```

## Отладка

Если возникают проблемы с копированием:

1. Проверьте права на запись в папку проекта
2. Убедитесь, что папки `registry/` и `adpi/` существуют или могут быть созданы
3. Проверьте консоль вывода - там будут сообщения:
   - `✅ Файл реестра скопирован в: <путь>`
   - `✅ Файл АДПИ скопирован в: <путь>`
   - `Предупреждение: не удалось скопировать файл...` (если ошибка)

## Обратная совместимость

- Все существующие функции загрузки/сохранения работают как раньше
- Конфигурационные файлы по-прежнему хранятся в отдельной папке конфигурации
- Старые настройки путей сохраняются и используются для диалоговых окон
