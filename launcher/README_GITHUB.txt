# AutoFormFiller - Система автоматического заполнения форм для семей

## 📋 Описание

AutoFormFiller - это комплексное решение для автоматического заполнения форм в базе данных на основе JSON файлов с информацией о семьях. Система состоит из двух основных компонентов:

1. **Создатель JSON файлов** - позволяет формировать и редактировать JSON файлы с данными семей
2. **Массовый обработчик** - автоматически заполняет формы в базе данных на основе JSON файлов
3. **Интеграция с Google Sheets** - закрашивает выполненные семьи в таблицах
4. **Графический интерфейс** - удобное управление через GUI

## ✨ Особенности

- **Графический интерфейс** на основе CustomTkinter
- **Поддержка загрузки данных** из Excel файлов (реестры, АДПИ)
- **Автоматическое определение семей** по ФИО
- **Валидация данных** перед сохранением
- **Возможность ручного вмешательства** при необходимости
- **Поддержка автосохранения данных**
- **Поддержка скриншотов** заполненных форм
- **Интеграция с Google Sheets** для отметки выполненных семей
- **Управление статусом окрашивания** в JSON файлах
- **Проверка существующих цветов** в таблице перед закрашиванием
- **Автоматическое сохранение и подстановка ID таблицы и названия листа**

## 🛠 Требования

- Python 3.7+
- Chrome, Yandex или Chromium браузер
- База данных (доступ к localhost:8080)
- Учетные данные Google API (для интеграции с Google Sheets)

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd AutoFormFiller
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

Если файл requirements.txt отсутствует, установите следующие пакеты:
```bash
pip install customtkinter selenium pandas openpyxl python-dateutil webdriver-manager google-api-python-client google-auth
```

3. Положите файл учетных данных Google API в корень проекта с именем `hale-sentry-478217-a7-e2f18fda44d4.json`

## 🚀 Запуск

### Лаунчер (рекомендуется)
```bash
python main.py
```

### Прямой запуск компонентов
```bash
# Запуск создателя JSON файлов
python main.py --mode creator

# Запуск массового обработчика
python main.py --mode processor
```

## 📖 Использование

### Лаунчер

При запуске `python main.py` открывается главное окно с выбором действия:

- **Создать JSON файлы** - запуск приложения для создания и редактирования JSON файлов с семьями
- **Массовая обработка** - запуск обработчика для автоматического заполнения форм
- **Клиент базы данных** - запуск клиента для работы с базой данных
- **Выделить завершенные семьи** - отметка выполненных семей в Google Sheets
- **Экспорт матерей в TXT** - экспорт ФИО матерей в текстовый файл

### Создатель JSON файлов

1. Запустите приложение в режиме создателя
2. Загрузите JSON файл с существующими семьями или создайте новые
3. Заполните данные о семье (родители, дети, доходы, жилье, АДПИ)
4. Используйте вкладку "Автоопределение" для загрузки данных из реестров
5. Сохраните данные в JSON файл

### Массовый обработчик

1. Запустите приложение в режиме обработчика
2. Загрузите JSON файл с семьями
3. Настройте параметры автоматизации
4. Начните процесс обработки
5. При необходимости используйте ручное вмешательство

### Интеграция с Google Sheets

#### Закрашивание выполненных семей

Система автоматически закрашивает выполненные семьи в Google Sheets зеленым цветом. Перед закрашиванием проверяется наличие уже установленных цветов (зеленого или желтого) в ячейках.

#### Автоматическое сохранение ID таблицы и названия листа

Система автоматически сохраняет ID Google-таблицы и названия листов в конфигурационный файл `config/app_config.json`. При последующих запусках ID и название подставляются автоматически с возможностью проверки и корректировки пользователем.

Пример использования автоматического сохранения:

```python
from utils.config_manager import get_default_config_manager
from utils.google_sheets_handler import get_both_ids_with_confirmation

# Получение ID таблицы и названия листа с автоматической подстановкой
config_manager = get_default_config_manager()
spreadsheet_id, sheet_name = get_both_ids_with_confirmation("АСП_Многодетные", config_manager)
```

#### Интерактивная обработка семей с уже установленным цветом

При обнаружении окрашенных ячеек пользователю предлагается выбрать:
- "да" - закрасить все семьи
- "нет" - пропустить все семьи
- "выбрать конкретные семьи" - интерактивный выбор

## 📁 Папки

- `autosave/` - автосохраненные данные
- `screenshots/` - скриншоты заполненных форм
- `logs/` - логи работы приложения
- `files for fill queue/` - файлы для обработки
- `completed/` - завершенные файлы

## 🔧 Файлы конфигурации

- `family_creator_config.json` - конфигурация создателя JSON файлов
- `mass_processor_config.json` - конфигурация массового обработчика
- `processing_statistics.json` - статистика обработки
- `app_config.json` - основная конфигурация приложения

Файлы конфигурации хранятся в папке `config/`.
